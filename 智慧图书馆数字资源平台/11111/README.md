## 快速开始

```bash
cd 02-源码
pip install -r requirements.txt
python 01_main.py
```

菜单 0 一键导入数据 → 1 核对（books 50 / readers 30 / borrow_logs 3000）→ 2~7 检索 →
13~16 统计 → 18~20 GridFS → 22 分片查询对比 → 99 退出。

数据库的启动、副本集初始化、分片集群搭建与账号说明，见 `03-数据库与配置/启动与部署说明.md`。

## 完成情况（对应任务一至七）

- **任务一 技术选型**：四类 NoSQL 差异、CAP 三场景分析、BASE 理论应用、两个风险与应对
- **任务二 数据建模**：逻辑结构层次、字段类型理由、12 个索引设计、borrow_logs 集合类型论证
- **任务三 单机实现**：11 项检索统计、索引前后执行计划对比、三账号权限验证
- **任务四 应用开发**：12 个模块、程序可直接运行、GridFS 上传/下载/字节校验
- **任务五 副本集**：一主两从、故障转移时间线与角色变化、keyFile 认证、节点增删
- **任务六 分片集群**：config/sh1/sh2/mongos 拓扑、hashed 分片键论证（≥500 字）、数据分布验证
- **任务七 验收交付**：核验脚本 + 图形化（Compass）结果与命令行一致
