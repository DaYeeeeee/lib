# 启动与部署说明（数据库与配置）

> **公开版说明**：本仓库为公开版。02-源码/config.json 的连接串密码已替换为占位符 CHANGE_ME，
> 副本集 keyFile 已移除（需自行生成）。按本文档顺序操作、把占位符换成你自己设置的密码即可完整复现。

## 1. 环境

- Windows / macOS / Linux；MongoDB 7.0+（mongod / mongos / mongosh）
- Python 3.10+ + pymongo（`pip install -r ../02-源码/requirements.txt`）
- 工程目录可整体拷贝到任意路径（代码不写死绝对路径，也不依赖当前工作目录）。

## 2. 副本集 rs0（任务三 / 任务五）

三个节点，keyFile 内部认证 + 账号授权。

先在各节点数据目录下生成 keyFile：
```bash
openssl rand -base64 756 > keyfile.txt
chmod 600 keyfile.txt  # Linux/macOS
```

启动三个 mongod 实例（以 macOS 为例，Windows 将路径改为反斜杠）：
```bash
mongod --port 27017 --dbpath ./rs1 --bind_ip 127.0.0.1 --replSet rs0 --keyFile ./keyfile.txt --fork --logpath ./rs1/mongod.log
mongod --port 27018 --dbpath ./rs2 --bind_ip 127.0.0.1 --replSet rs0 --keyFile ./keyfile.txt --fork --logpath ./rs2/mongod.log
mongod --port 27019 --dbpath ./rs3 --bind_ip 127.0.0.1 --replSet rs0 --keyFile ./keyfile.txt --fork --logpath ./rs3/mongod.log
```

初始化副本集（也可用 `cd ../02-源码 && python init_repl.py`）：
```javascript
rs.initiate({
  _id: "rs0",
  members: [
    { _id: 0, host: "127.0.0.1:27017", priority: 2 },
    { _id: 1, host: "127.0.0.1:27018", priority: 1 },
    { _id: 2, host: "127.0.0.1:27019", priority: 1 }
  ]
})
```

创建账号（localhost 例外窗口内创建，三个节点任选其一执行一次即可，账号会自动同步到整个副本集）：

| 账号 | 认证库 | 角色 | 密码 |
|---|---|---|---|
| lib_admin | admin | dbOwner(smart_library), userAdminAnyDatabase, clusterAdmin | <自行设置> |
| lib_reader | smart_library | read | <自行设置> |
| lib_writer | smart_library | readWrite | <自行设置> |

```javascript
// 1) 管理员账号（认证库 admin；dbOwner(smart_library) 负责建索引，
//    userAdminAnyDatabase + clusterAdmin 负责管理用户与集群）
db.getSiblingDB("admin").createUser({
  user: "lib_admin", pwd: "<你的密码>",
  roles: [{ role: "dbOwner", db: "smart_library" },
          { role: "userAdminAnyDatabase", db: "admin" },
          { role: "clusterAdmin", db: "admin" }]
});

// 2) 只读账号（认证库 smart_library，只能查询，写入会被拒绝）
db.getSiblingDB("smart_library").createUser({
  user: "lib_reader", pwd: "<你的密码>",
  roles: [{ role: "read", db: "smart_library" }]
});

// 3) 读写账号（认证库 smart_library，普通业务增删改查）
db.getSiblingDB("smart_library").createUser({
  user: "lib_writer", pwd: "<你的密码>",
  roles: [{ role: "readWrite", db: "smart_library" }]
});
```

创建完毕后，重启各节点并添加 `--auth` 参数启用认证。注意：`MONGODB_URI` 等连接串中的用户名需与上文账号完全一致（`lib_writer` / `lib_reader` / `lib_admin`）。

## 3. 分片集群（任务六）

端口规划：config 副本集 27200、分片 sh1 27301、sh2 27302、mongos 27300。

```bash
# 启动 config server
mongod --port 27200 --dbpath ./shard_test/config --configsvr --replSet cfgRS --bind_ip 127.0.0.1 --fork --logpath ./shard_test/config/mongod.log

# 初始化 config 副本集
mongosh --port 27200 --eval 'rs.initiate({_id:"cfgRS", members:[{_id:0,host:"127.0.0.1:27200"}]})'

# 启动两个 shard（MongoDB 7.0 起 --shardsvr 节点必须作为副本集启动，否则报
# “Cannot start a shardsvr as a standalone server”，故两个分片各是单成员副本集）
mongod --port 27301 --dbpath ./shard_test/shard1 --shardsvr --replSet shard1rs --bind_ip 127.0.0.1 --fork --logpath ./shard_test/shard1/mongod.log
mongod --port 27302 --dbpath ./shard_test/shard2 --shardsvr --replSet shard2rs --bind_ip 127.0.0.1 --fork --logpath ./shard_test/shard2/mongod.log

# 初始化两个 shard 的副本集（等待几秒后再执行）
mongosh --port 27301 --eval 'rs.initiate({_id:"shard1rs", members:[{_id:0,host:"127.0.0.1:27301"}]})'
mongosh --port 27302 --eval 'rs.initiate({_id:"shard2rs", members:[{_id:0,host:"127.0.0.1:27302"}]})'

# 启动 mongos（config 副本集 PRIMARY 选出后再启）
mongos --port 27300 --configdb cfgRS/127.0.0.1:27200 --bind_ip 127.0.0.1 --fork --logpath ./mongos.log
```

通过 mongos 添加分片并启用：
```javascript
sh.addShard("shard1rs/127.0.0.1:27301")
sh.addShard("shard2rs/127.0.0.1:27302")
sh.enableSharding("smart_library")
sh.shardCollection("smart_library.borrow_logs", { book_isbn: "hashed" })
```

## 4. 程序运行

config.json 保存连接串；把 CHANGE_ME 替换成实际密码后：

```bash
cd ../02-源码
pip install -r requirements.txt
python 01_main.py
```

也可用环境变量覆盖：

```bash
# macOS / Linux
export MONGODB_URI="mongodb://lib_writer:<密码>@127.0.0.1:27017,127.0.0.1:27018,127.0.0.1:27019/?replicaSet=rs0&authSource=smart_library"
export MONGODB_DB=smart_library
python 01_main.py
```

**工作目录无关**：代码里所有文件路径都以 `os.path.dirname(os.path.abspath(__file__))` 为基准，
所以在任意目录下用完整路径运行都可以。

## 6. 老师如何检验「多端口 / 多节点」

### 方式一：一条命令看端口（30 秒）

```bash
# macOS / Linux
lsof -iTCP -sTCP:LISTEN -P -n | grep -E "27017|27018|27019|27200|27301|27302|27300"

# Windows
netstat -ano | findstr "27017 27018 27019 27200 27301 27302 27300"
```

### 方式二：核验脚本（推荐）

```bash
cd 03-数据库与配置
python verify_topology.py
```

输出：端口监听状态、副本集角色与优先级、分片数据分布百分比。

### 方式三：MongoDB Compass 图形化

1. 副本集：连接 `127.0.0.1:27017,127.0.0.1:27018,127.0.0.1:27019`，Replica Set Name 填 `rs0`
2. 分片集群：连接 `127.0.0.1:27300`（mongos 入口）

## 7. 复现要点

1. 先起副本集，再起分片集群（端口互不冲突）。
2. 分片数据分布验证一律通过 mongos，不要直连分片节点。
3. 故障转移演练：停止主节点 → 观察选举 → 重启原主节点（作为 SECONDARY 回归）。
